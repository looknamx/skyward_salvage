# Skyward Salvage

เกมยิงผลัดกันเล่นบนเว็บสำหรับ 2–4 คนในห้องส่วนตัว พัฒนาจากภาพแนวทางที่อนุมัติแล้ว โดยแยกจากโครงการ `arcane_relay`.

ดูค่าสถานะรถ ดาเมจ DEF ท่าพิเศษ ของสวมใส่ และสภาพอากาศได้ที่ [หน้า Wiki](public/wiki.html) หรือ [เอกสาร Wiki](WIKI.md) เมื่อเปิดเกมแล้วเข้า `/wiki.html` เพื่อดูการ์ดรถพร้อมภาพและตัวกรอง

![หน้าจอเกมจริงหลังปรับปรุง: ห้องสี่ผู้เล่น](art_review/game-after.jpg)

## เริ่มเล่นบนเครื่องนี้

ต้องมี Node.js 20.19+ หรือ 22.12+.

```powershell
cd D:\workshop\skyward_salvage
npm install
npm run dev
```

เปิด `http://localhost:5173` สร้างห้อง แล้วส่งลิงก์ห้องให้เพื่อนอีก 1–3 คน หากเปิดจากเครื่องอื่นในเครือข่ายเดียวกัน ให้ใช้ IP ของเครื่องที่รันเซิร์ฟเวอร์แทน `localhost` และเปิดพอร์ตที่เกี่ยวข้องตามการตั้งค่าเครือข่ายของคุณ

## รันแบบเซิร์ฟเวอร์เดียว

```powershell
npm run build
npm start
```

เปิด `http://localhost:3001` หรือกำหนด `PORT` ก่อนสั่ง `npm start`. การเล่นกับเพื่อนผ่านอินเทอร์เน็ตต้องนำ Node server นี้ขึ้นโฮสต์ที่เข้าถึงได้จากภายนอก พร้อม HTTPS/WSS. โค้ดเกมและห้องออนไลน์พร้อมใช้งาน แต่ยังไม่ได้เผยแพร่ไปยังโฮสต์สาธารณะ

หากใช้โดเมนสาธารณะ ให้ตั้ง `ALLOWED_ORIGINS` เป็น origin ที่อนุญาต คั่นหลายค่าด้วยจุลภาค เช่น `https://game.example.com` เซิร์ฟเวอร์ตรวจ Origin ของ WebSocket, จำกัดขนาดข้อความและความถี่คำสั่ง และตรวจการเชื่อมต่อที่ค้างด้วย ping/pong. ห้องและสถิติยังอยู่ในหน่วยความจำของ Node process เดียว จึงควรตั้งโฮสต์ให้ทำงานต่อเนื่องระหว่างแมตช์

## เล่นกับเพื่อนผ่าน Cloudflare Quick Tunnel บน Windows

ติดตั้ง `cloudflared` และ dependencies ของเกมก่อน จากโฟลเดอร์โปรเจกต์เรียก:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\Start-Tunnel.ps1
```

สคริปต์ build เกม แล้วเปิดเซิร์ฟเวอร์และ Tunnel เป็นโปรเซสเบื้องหลัง แสดงลิงก์ HTTPS สำหรับส่งให้เพื่อน ลิงก์ล่าสุดเก็บไว้ใน `.tunnel/url.txt` และ logs อยู่ใน `.tunnel/`. ใช้ `-SkipBuild` เมื่อไม่ต้อง build ใหม่ หรือ `-Port 3002` หากพอร์ต 3001 ถูกใช้อยู่แล้ว สคริปต์ใช้การตรวจ Origin แบบ host เดียวกันตามระบบเดิม

ปิดเซิร์ฟเวอร์และ Tunnel ด้วย:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\Stop-Tunnel.ps1
```

เปิดคอมและรักษาการเชื่อมต่ออินเทอร์เน็ตไว้ตลอดที่เล่น อย่าให้เครื่อง Sleep. ลิงก์จะเปลี่ยนเมื่อเปิด Tunnel ใหม่ และห้องเกมจะหายเมื่อเซิร์ฟเวอร์หยุด Quick Tunnel เป็นบริการสำหรับทดลอง/พัฒนา ไม่มีการรับประกัน uptime: https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/

## ลิงก์ทางเข้าคงที่ด้วย ngrok และ Cloudflare Quick Tunnel

ติดตั้ง ngrok และตั้ง authtoken ในเครื่องก่อน จากนั้นเปิดทั้งเกม, Cloudflare และหน้า redirect ผ่านโดเมนฟรีประจำบัญชีด้วยคำสั่งเดียว:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\Start-Online.ps1 -Hostname gulf-headed-capsule.ngrok-free.dev
```

ครั้งต่อไปเรียก `scripts\Start-Online.ps1` ได้โดยไม่ต้องระบุ Hostname เพราะจำไว้ใน `.tunnel/gateway.json` ใช้ `-SkipBuild` เมื่อไม่มีการแก้เกม สคริปต์เปิดโปรเซสเบื้องหลังทั้งหมดและบันทึกลิงก์สำหรับแชร์ใน `.tunnel/share-url.txt` ปิดทั้งหมดด้วย `scripts\Stop-Tunnel.ps1` ตามเดิม

เพื่อนเปิดลิงก์ ngrok เดิมแล้วระบบ redirect แบบไม่ cache ไปยัง Cloudflare ล่าสุด พร้อมเก็บ path และ query เช่น `?room=ABC123` การโหลดเกม ภาพ เสียง และ WebSocket เกิดที่ Cloudflare หลัง redirect แล้ว หน้า gateway ตรวจ `/health` ของปลายทางก่อนส่งต่อ หากปลายทางไม่พร้อมจะแสดงหน้าเกมยังไม่ออนไลน์และลองใหม่ทุก 5 วินาที เมื่อปิด ngrok ด้วย ลิงก์ทางเข้าจะแสดงสถานะ offline ของ ngrok แทน

ngrok Free อาจแสดงหน้าให้กด Visit Site ก่อนเข้าครั้งแรก และมีโควตาตามบัญชี ไม่ใช่ระบบย้ายการเชื่อมต่อแมตช์สดเมื่อ Cloudflare เปลี่ยนลิงก์: ผู้เล่นต้องเปิดลิงก์ทางเข้าใหม่ในกรณีดังกล่าว Credentials ของ ngrok อยู่ใน config ของผู้ใช้และไม่เข้า Git ส่วน `.tunnel/` ถูก ignore ทั้งโฟลเดอร์

## แผงเปิด / ปิดเกมจาก Bookmark

เปิด `http://localhost:3010` บนเครื่องที่โฮสต์เกม แล้วบันทึกไว้ใน Bookmark หน้าแผงควบคุมมีสองปุ่ม **เปิดเกม** และ **ปิดเกม** พร้อมสถานะการเชื่อมต่อและลิงก์ ngrok สำหรับส่งให้เพื่อน ปุ่มเปิดเกม build เวอร์ชันปัจจุบันและเปิดเกม/Cloudflare/ngrok ส่วนปุ่มปิดหยุดทั้งสี่โปรเซสและสิ้นสุดห้องเกมที่อยู่ในหน่วยความจำ หน้าแผงควบคุมยังเปิดอยู่และกดเปิดเกมใหม่ได้

เปิดแผงควบคุมด้วยตัวเอง:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\Start-ControlPanel.ps1
```

ตั้งให้แผงควบคุมเปิดเบื้องหลังเมื่อเข้า Windows (ไม่ได้เปิดเกมอัตโนมัติ):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\Install-ControlPanelStartup.ps1
```

การตั้งค่านี้สร้าง shortcut `Skyward Salvage Control Panel.lnk` ใน Startup ของผู้ใช้ หากต้องการยกเลิกให้เปิด `shell:startup` แล้วลบ shortcut นี้ แผงควบคุมฟังเฉพาะ `127.0.0.1:3010` และตรวจ Host/Origin กับ token ประจำการเปิดแผงก่อนรับคำสั่ง POST ไม่ได้เปิดผ่านลิงก์ ngrok/Cloudflare ผู้เล่นภายนอกจึงไม่สามารถสั่งปิดเกมจากหน้าแผงนี้

## ลิงก์ถาวรด้วย Cloudflare Named Tunnel

ต้องมีโดเมนที่ active ในบัญชี Cloudflare ก่อน ตั้งค่าครั้งเดียวโดยแทน `game.example.com` ด้วยชื่อโฮสต์ที่ต้องการ:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\Setup-NamedTunnel.ps1 -Hostname game.example.com
```

สคริปต์เปิดให้ล็อกอิน Cloudflare ถ้ายังไม่มีใบรับรอง สร้างหรือใช้ Tunnel ชื่อ `skyward-salvage` และเพิ่ม DNS โดยไม่เขียนทับ record ที่ใช้งานอยู่ เก็บ config ใน `.tunnel/` ซึ่งไม่เข้า Git ส่วน credentials อยู่ในโฟลเดอร์ `.cloudflared` ของผู้ใช้ หากใช้พอร์ตอื่นให้ระบุ `-Port` ตอน setup

หลัง setup สำเร็จ ใช้ `Start-Tunnel.ps1` และ `Stop-Tunnel.ps1` ตามเดิม โดย Start จะใช้ Named Tunnel อัตโนมัติและแสดงลิงก์เดิมทุกครั้ง ถ้ายังไม่มี named config จะใช้ Quick Tunnel ตามเดิม ไม่ต้องมี IP บ้านคงที่หรือเปิดพอร์ตเราเตอร์ แต่เครื่องและอินเทอร์เน็ตต้องเปิดตลอดที่เล่น

## วิธีเล่น

1. ใส่ชื่อแล้วสร้างหรือเข้าห้องด้วยรหัส 6 ตัว จากนั้นเลือก Mobile ในตู้ Slot จาก Loom, Manta, Borer, Vesper, Bramble, Halo, Kestrel, Cinder, Gale และ Tempest หรือเลือก **? สุ่ม Mobile** แล้วเลื่อนกลับไปเลือกรถอื่นได้ก่อนกดพร้อม ผลสุ่มจะเปิดเผยเมื่อเข้าหน้าจอเกมเท่านั้น (มีโอกาส 5% ได้ Aegis พลังชีวิต 150) หมวก เกราะ และธงแต่ละช่องมีตัวเลือก **? สุ่มของสวมใส่** ซึ่งสุ่มได้ชุดสีทอง 5% (แต่ละชิ้น ATK +3, DEF +3, เลือด +3) ส่วนอีก 95% แบ่งสามชุดเดิมเท่ากันเมื่อเริ่มเกม และเปลี่ยนตัวเลือกได้ก่อนกดพร้อม หากต้องการทดลองคนเดียว เลือก Mobile แล้วกด **ฝึกยิงคนเดียว** ที่หน้าแรก
2. ผู้เล่นที่ไม่ใช่หัวหน้าห้องกด **พร้อมเล่น** หลังเลือก Mobile แล้ว หัวหน้าห้องเลือกระหว่างทุกคนสู้กันและทีม 2v2 แล้วกดเริ่มเมื่อมี 2–4 คนและทุกคนพร้อม โหมดทีมต้องมี 4 คน ทีม A/B สลับตามลำดับเข้าห้องและกระสุนไม่ทำร้ายเพื่อนร่วมทีม
3. เทิร์นของคุณมี 30 วินาที กด **←/→ หรือ A/D** เพื่อเดินตามพื้นสนามได้รวมสูงสุด 175 หน่วยต่อเทิร์น (ประมาณหนึ่งคันครึ่ง) และ **↑/↓ หรือ W/S** เพื่อปรับมุมยิง 10–80° จากด้านหน้ารถ กด **R** เพื่อหันไปยิงอีกฝั่งโดยไม่ต้องเดิน บนมือถือกดปุ่ม **⚙ ตั้งค่า** มุมขวาบนเพื่อเปิดปุ่มลูกศรบนหน้าจอ
4. กดปุ่ม **FIRE** หรือ **Space** ค้างไว้เพื่อชาร์จพลังจาก 5% ถึง 100% แถบ POWER จะค่อย ๆ เพิ่ม แล้วปล่อยปุ่มเพื่อยิง
5. ดูทิศและแรงลมบน HUD. ทุกคันเริ่มเล็งที่ 45° จากด้านหน้ารถ และจำมุมล่าสุดไว้สำหรับเทิร์นต่อไป ลมมีโอกาสเปลี่ยน 20% เมื่อขึ้นเทิร์นใหม่ รถจะเอียงตามพื้นสนามหลังถูกยิงจนเปลี่ยนรูป
6. ไอเทม **Double Play** (ช่อง 4) เพิ่มเทิร์นต่อเนื่องอีกหนึ่งเทิร์นหลังจบเทิร์นปัจจุบัน เริ่มเวลา 30 วินาทีและระยะเดินใหม่ จากนั้นกลับลำดับปกติ; เริ่มรอบมีหนึ่งชิ้น ใช้ร่วมกับการยิง ซ่อม หรือวาร์ปได้ หากรถตายหรือผู้เล่นหลุดจะไม่ได้เทิร์นเพิ่ม ไอเทม **×2** เพิ่มดาเมจของนัดถัดไป 2 เท่า, **ซ่อม** ฟื้น 28 HP แล้วจบเทิร์น, **ย้าย** กดเลือกไอเทม เล็งมุม แล้วชาร์จยิงกระสุนวาร์ปไปยังจุดตกเพื่อย้ายตำแหน่งและจบเทิร์น
7. ปุ่ม **ท่าพิเศษ** ใช้ได้หนึ่งครั้งต่อรอบ และเติมใหม่ได้เมื่อเก็บไอเทมท่าพิเศษหลังใช้ไปแล้ว: Loom ยิงแม่นและแรงขึ้น, Manta แตกเป็นสามกระสุน, Borer ระเบิดพื้นที่กว้างขึ้น, Vesper ยิงโดยไม่ถูกลมพัด, Bramble ยิงพร้อมฟื้นพลังให้ตัวเอง, Halo ยิงแม่นโดยไม่ถูกลมพัด, Kestrel แตกเป็นสามกระสุน และ Cinder ระเบิดพื้นที่กว้างขึ้น
8. ทุก ๆ 8 เทิร์นจะมีไอเทมแบบสุ่มตกลงบนสนาม: ×2, ซ่อม และย้าย และ Double Play อย่างละ 23%; เติมท่าพิเศษ 8% เดินหรือย้ายตำแหน่งไปเก็บได้เมื่อช่องของไอเทมชนิดนั้นว่าง
9. ไม่มีเส้นคาดการณ์วิถีกระสุนระหว่างเล็ง ต้องกะระยะจากมุม พลัง และแรงลมเอง
10. ผู้เล่นหรือทีมสุดท้ายที่เหลือ HP ชนะ หลังจบรอบมีสถิติ จากนั้นทุกคนกดรีแมตช์เพื่อกลับห้องเตรียมเกม เลือกรถใหม่และกดพร้อมก่อนหัวหน้าห้องเริ่มรอบต่อไป

ระหว่างเลือก Mobile ในห้องเตรียมเกม สามารถใส่หมวก เสื้อ/เกราะ และธงแยกกันได้ แต่ละช่องเลือกจากสามชุดหรือเว้นว่าง ชุดโจมตีเพิ่มดาเมจกระสุนชิ้นละ 5, ชุดป้องกันลดดาเมจกระสุนที่ได้รับชิ้นละ 5 และชุดเลือดเพิ่ม HP สูงสุดชิ้นละ 5 ผสมชิ้นส่วนข้ามชุดได้ คู่แข่งจะไม่เห็นชุดที่เลือกจนกว่าเกมเริ่ม

ตู้ปรับแต่งมี 4 ช่อง: รถ หมวก เกราะ และธง คลิกภาพข้างบน/ล่าง กดลูกศรบนตู้ ใช้ล้อเมาส์ หรือปัดขึ้นลงเพื่อเลือกแต่ละช่อง ในเกมกดปุ่มเลข **1–5** (รวมแป้นตัวเลข) เพื่อใช้ไอเทม ×2, ซ่อม, ย้าย, Double Play และท่าพิเศษตามลำดับ

ทุกครั้งที่ขึ้นเทิร์นใหม่มีโอกาส 3% ที่อุกกาบาตหนึ่งลูกจะตกบนสนาม หากตกโดน Mobile โดยตรงจะเสีย 20 HP และพื้นที่รอบจุดตกจะกลายเป็นหลุมกว้าง (รัศมี 91 หน่วย) ดาเมจอุกกาบาตไม่ถูกลดด้วยชุดป้องกัน โหมดฝึกไม่มีอุกกาบาต

โหมดฝึกมีเป้านิ่งที่ฟื้นพลังหลังทุกนัด เล่นได้โดยไม่จับเวลาและไม่ต้องรอผู้เล่นอื่น เลือก Mobile ได้ที่หน้าแรก หรือเปลี่ยนคันใน **ตั้งค่า → Mobile สำหรับฝึก** รวมถึง Aegis การเปลี่ยนคันจะคืนสนามและไอเทมทั้งหมด ใช้ปุ่มตั้งค่าเพื่อเริ่มสนามฝึกใหม่หรือออกจากโหมดฝึก

หากเน็ตหลุดหรือรีเฟรชหน้าเดิม เบราว์เซอร์จะกลับเข้าห้องอัตโนมัติภายใน 45 วินาที เทิร์นของผู้ที่หลุดจะผ่านไปเพื่อไม่ให้ทั้งห้องรอ เมื่อหมดเวลาดังกล่าวผู้เล่นที่ยังไม่กลับจะถูกนำออกจากรอบ

กด **⚙ ตั้งค่า** ระหว่างเกมเพื่อเปิด/ปิด **BGM** และ **SFX** แยกกันได้ ตัวเลือกจะจำไว้ในเบราว์เซอร์ SFX รวมเสียงเลื่อนตู้สล็อต เดินรถ ยิง ถูกยิง ไอเทม ท่าพิเศษ ไอเทมตก ลมเปลี่ยน และเสียงนาฬิกาเตือนใน 5 วินาทีสุดท้ายของเทิร์น

## โครงสร้าง

- `shared/game.ts` — กติกา ฟิสิกส์เทิร์น ลม กระสุน พื้นและไอเทม
- `server/index.ts` — ห้องส่วนตัวและสถานะเกมที่เซิร์ฟเวอร์เป็นผู้ตัดสิน
- `src/GameScene.ts` — ภาพสนาม Mobile และเอฟเฟกต์ใน Phaser

- `public/assets/environment/` — ฉากหลังจาก imagegen
- `public/assets/terrain/` — ผิวหินของเกาะลอยฟ้าจาก imagegen

- `public/assets/sound/` — เพลงพื้นหลังและเสียงเอฟเฟกต์ที่ใช้ในเกม

## การแสดงผลตอนจบรอบและจอกว้าง

### พื้นทะลุและกระสุนแตกตัว

ขอบใต้เกาะกำหนดคงที่เมื่อเริ่มรอบ การระเบิดซ้ำจะขุดพื้นลึกขึ้นจนทะลุเป็นช่องว่าง Mobile ที่ไม่มีพื้นรองรับหรือเดินตกช่องจะตายทันทีและมีภาพตกลงด้านล่าง ผู้ยิงที่ขุดจนคู่แข่งตกจะได้สถิติการโจมตีด้วย ไอเทมบนพื้นบริเวณที่ทะลุจะหายไป โหมดฝึกจะคืนสนามเมื่อจุดของผู้ฝึกหรือเป้าไม่มีพื้นรองรับ

Manta และ Kestrel ยิงกระสุนหลักหนึ่งลูกจนกระทบพื้นก่อนแตกกระเด้งเป็นสองลูก (ท่าพิเศษสามลูก) กระสุนย่อยชน Mobile ที่อยู่ใกล้ได้ระหว่างกระเด้งและทำดาเมจตามปกติ ภาพกระสุนใช้จังหวะร่วมกันก่อนจุดแตกตัว จึงไม่ปรากฏการแยกกลางอากาศ

แต่ละ Mobile มีสีและรูปทรงกระสุนต่างกัน ท่าพิเศษมีวงพลังและประกายที่เด่นกว่ากระสุนปกติ เมื่อ Mobile ถูกกำจัดจะมีเอฟเฟกต์ระเบิดหรือเศษชิ้นส่วนตกตามสาเหตุ ค่ามุมบน HUD และเข็มหน้าปัดแสดงทิศกระสุนจากปากกระบอกจริงโดยรวมความเอียงของพื้น ส่วนสไลเดอร์ยังใช้ปรับมุม 10–80 องศาเทียบกับตัวรถ

แต่ละเทิร์นที่ไม่มีสภาพอากาศมีโอกาส 10% ที่จะเกิดแถบในตำแหน่งสุ่มทั่วสนาม จากนั้นสุ่มชนิดระหว่างสายฟ้า พายุ และฝนอย่างเท่า ๆ กัน เมื่อเกิดแล้วจะอยู่ 4 เทิร์นรวมเทิร์นที่เริ่ม และไม่มีสภาพอากาศอื่นมาทับ แถบแสดงในสนามโดยไม่มีป้ายชื่อหรือจำนวนเทิร์น กระสุนต้องผ่านแถบก่อนโบนัสจึงทำงาน: สายฟ้าเพิ่มดาเมจ +5 เมื่อโดนรถ, พายุเพิ่มแรงลมอีก 2 หน่วยตามทิศพายุหลังผ่านแถบ, ฝนทำให้รถที่โดนกระสุนใช้ไอเทมและท่าพิเศษไม่ได้ในเทิร์นถัดไป กระสุนที่ไม่ผ่านแถบใช้กติกาเดิม

เมื่อจบรอบ เกมแสดงกระสุน ระเบิด และอุกกาบาตสุดท้ายให้เสร็จก่อน แล้วรออีก 5 วินาทีจึงเปิดหน้าสรุปผู้ชนะ ระหว่างนี้คำสั่งเล่นถูกปิดแล้ว สถานะจบรอบที่ส่งซ้ำจะไม่เริ่มนับใหม่ และการกลับห้องเตรียมเกมยกเลิก popup ที่กำลังรอ

ฉากตกแต่งที่อยู่หลังสนามขยายเต็ม viewport และเปลี่ยนตามแผนที่ปัจจุบัน ใช้ภาพฉากเดิมร่วมกับการเบลอเล็กน้อยเพื่อเติมช่องว่างทั้งด้านข้างและด้านบน/ล่าง ส่วนสนามจริงและพิกัดฟิสิกส์ยังเป็น 1280 × 720
