# Settings and direction control icons

Generated with the built-in ImageGen tool. Original generated PNGs remain in the Codex image output directory. Runtime images were normalized to 256 × 256 RGBA PNGs with transparent outer backgrounds.

- `public/assets/ui/settings-icon.png`: Settings cog.
- `public/assets/ui/direction-arrow.png`: Up arrow; CSS rotates the same image into left, right and down directions. Also used on the lobby slot reels.

Accessible button labels and pointer/keyboard control handlers are preserved. Decorative images have empty alt text, do not accept pointer events, and cannot be dragged. Random-Mobile text no longer uses a dice emoji.

## Settings prompt

Create a single game UI SETTINGS GEAR icon for Skyward Salvage, a hand-painted fantasy steampunk floating-island artillery game. Square canvas, only one perfectly centered front-facing 10-tooth ivory/silver mechanical cog, subtle warm brass edge trim and a glowing turquoise central hub. Bold clean silhouette and restrained detail readable at 24 pixels. Slight beveled volume, soft painted highlights. NO surrounding button or tile or frame, no text, no letters, no emoji, no extra objects. True transparent alpha background, generous equal 12 percent padding on all sides, no external shadow. Asset intended to sit inside an existing dark navy teal edged square HUD button. Match polished illustrated fantasy brass/teal interface styling.

## Arrow prompt

Create a single game UI DIRECTION ARROW icon for Skyward Salvage, a hand-painted fantasy steampunk floating-island artillery game. Square canvas, one perfectly centered thick arrow pointing straight UP. Broad triangular arrowhead and short solid stem, connected as one shape. Ivory/silver metal face with subtle warm brass edge trim and tiny turquoise bevel accents. Bold very simple symmetrical silhouette easily readable at 24 pixels, restrained painted highlights and slight beveled volume. NO gear, no surrounding button, tile or frame, no text, no lettering, no emoji, no additional arrows. True transparent alpha background with generous equal 12 percent padding on all sides, no external shadow. Intended to rotate into four directions and sit inside an existing dark navy teal edged square HUD button. Match polished illustrated fantasy brass/teal interface styling.
