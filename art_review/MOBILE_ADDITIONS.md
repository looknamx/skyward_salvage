# Vesper and Bramble Mobile sprites

Both sprites were created with the built-in ImageGen tool and saved as transparent 1254×1254 PNG files in `public/assets/characters/`. They use the established brass, navy, and painterly sky-island vehicle direction. Existing Mobile sprites were used as visual guidance during review; no existing sprite was overwritten.
