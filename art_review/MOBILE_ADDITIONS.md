# Vesper and Bramble Mobile sprites

Both sprites were created with the built-in ImageGen tool and saved as transparent 1254×1254 PNG files in `public/assets/characters/`. They use the established brass, navy, and painterly sky-island vehicle direction. Existing Mobile sprites were used as visual guidance during review; no existing sprite was overwritten.

## Final prompts

### Vesper

> Use case: stylized-concept. Asset type: production-ready transparent 2D sprite for Skyward Salvage side-view turn-based artillery game. Create ONE brand-new original Mobile named VESPER: a low, compact four-wheeled fantasy artillery vehicle with a crescent-shaped violet glass energy resonator and short forward-pointing cannon on the RIGHT. Distinct deep violet and amethyst body, aged brass and dark navy metal trim, tiny warm lanterns, expressive elegant silhouette. Painterly high-detail hand-painted 2D game illustration, clear readable outline at 112px, three-quarter side view facing right, full vehicle including wheels, centered with generous clear padding, roughly square canvas. Rich material detail and soft highlights consistent with whimsical brass fantasy sky-island vehicles. Actual transparent alpha background, isolated object only. No ground, sky, shadow plate, border, text, letters, logos, UI, extra vehicles, humans, or projectiles. Do not imitate any existing named game's characters.
